# Sunwings Transport Admin UI

Standalone Sunwings workspace inside the Justinnovate Website Admin repository.

This folder owns only Sunwings Transport administration:

- Service Posts
- Location Posts
- Quote Requests
- Sunwings website settings

It does not import or expose JustinDeMatteis Work/AI content, JustConsignIn workflows, or Wheels workflows.

Backend ownership lives under:

```
/api/admin/sunwings/
```

Services and Locations are managed as post-style records with their own list and editor screens.
