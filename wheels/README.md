# Wheels Admin UI

Standalone Wheels workspace inside the Justinnovate Website Admin repository.

This folder contains the frontend shell only. It intentionally does not create campaigns, write tracking data, generate QR codes, or modify the JustinDeMatteis / JustConsignIn backends.

Open `wheels/index.html` to view the responsive dashboard shell.

## Sections

- Dashboard
- Campaigns
- Tracking Links
- QR Codes
- Referrals
- Customers

The dashboard switcher exposes JustinDeMatteis.com, JustConsignIn.com, and Wheels. The other two destinations are intentionally not hard-coded here until the parent admin frontend owns the final route mapping.
